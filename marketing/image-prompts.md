# Event image prompts for ChatGPT

How to use:
1. In ChatGPT, paste a prompt below, one per message. Each one is complete on its own.
2. Download the image and rename it to the file name shown (e.g. `sbm-preschool-storytime.png`).
3. Send the images back to Claude in chat (or drop them in `public/img/events/`). Claude crops them, attaches each to its event, and credits them as "AI illustration".

Tip: if you like the first image's look, tell ChatGPT "Use the same style for the next ones."
