## §0 The tagged link (30 seconds, saves us guessing)

Last week's Facebook posts brought **49 signups**, but the links had no tag, so we can't tell which group did it. Before you post, swap the group name into the link:

`https://springbranchlittles.com/join/?source=fb-` + **short group name, lowercase, dashes**

Examples:
- Spring Shadows Moms Club → `https://springbranchlittles.com/join/?source=fb-spring-shadows-moms`
- Memorial Villages Moms → `https://springbranchlittles.com/join/?source=fb-memorial-villages-moms`
- Spring Branch Neighbors → `https://springbranchlittles.com/join/?source=fb-spring-branch-neighbors`

Any spelling works, as long as it's the same each time you post in that group. Facebook shows a preview card either way.
