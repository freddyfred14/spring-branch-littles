# Spring Branch Littles

Static site + newsletter + Instagram carousel for families with kids in Spring Branch, Houston.

- Content lives in `data/` (JSON). Code in `src/` and `scripts/` has no dependencies except Playwright (for slide images).
- `npm run check` validates data; `npm run build` writes `dist/`; `npm run serve` previews it.
- The weekly research job follows `AGENTS.md`. When updating listings, follow that file.
